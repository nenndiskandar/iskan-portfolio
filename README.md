# iskan-portfolio - Portfolio Showcase

Portfolio showcase with responsive design, WCAG AA compliant, teal accent theme.

## Tech Stack
- **Port**: 3004
- **Frontend**: Express static (zero-dep)
- **Framework**: WebJS (Express-based)

## Quick Start
npm install
npm start
Server: http://localhost:3004

## Features
- Responsive portfolio showcase
- Zero external dependencies
- Anti-AI bots protection
- Noindex headers
